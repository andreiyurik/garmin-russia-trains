# Публикация и установка на часы

## На свои часы по USB (до магазина)

```sh
./release.sh install fenix6 --home Одинцово --work Беговая --walk 7
```

Модель — одна из `product id` в `watch/manifest.xml`. Скрипт собирает
release-версию и копирует её в `GARMIN/APPS` подключённых часов. Если часы не
найдены, файл остаётся в `bin/release/Elektrichki-<модель>.prg` — его можно
скопировать вручную (fēnix 6 видна как флешка; vívoactive 5/6 — по MTP,
например через файловый менеджер).

Станции задаются при сборке (`--home`, `--work`, `--switch <час>`,
`--walk <мин>`, `--hide-express`): Garmin Connect не даёт менять настройки
приложений, установленных не из магазина. Чтобы сменить станции, соберите и
скопируйте заново; если часы оставили старые значения, удалите файл настроек
приложения в `GARMIN/APPS/SETTINGS` и скопируйте ещё раз.

Что проверить на часах: гланс и экран, фоновое обновление за ночь (утром
расписание на сегодня без открытия виджета), «Обновить сейчас» в меню, работу
без телефона. Если приложение падает, отчёт лежит в `GARMIN/APPS/LOGS/CIQ_LOG.YML`;
адреса из него расшифровываются по `bin/release/Elektrichki-<модель>.prg.debug.xml`.

Перед установкой из магазина удалите `GARMIN/APPS/Elektrichki.prg`.

## Бета через Connect IQ Store

`./release.sh beta` → `bin/release/Elektrichki-beta.iq`: то же приложение с
отдельным `id` (`BETA_ID` в `release.sh`) и «Beta» в названии. Бета в Connect
IQ навсегда остаётся бетой, поэтому `id` из манифеста для неё не годится.
Загружать с галочкой «Beta App», обновлять — новым пакетом в ту же карточку
беты. Её видит и ставит только владелец аккаунта: Connect IQ на телефоне →
My Apps. Настройки — в Garmin Connect, как у опубликованного приложения.

## В Connect IQ Store

1. Кабинет разработчика: <https://apps.garmin.com/developer/upload> — вход
   аккаунтом Garmin, принять соглашение разработчика.
2. Пакет: `./release.sh iq` → `bin/release/Elektrichki.iq` (все устройства из
   манифеста, без отладочной информации).
3. Загрузить пакет, указать версию (`1.0.0`), заполнить карточку текстами из
   [`listing.md`](listing.md), картинки — `store/hero.jpg` (1440×720),
   `store/icon.png` (обложка 500×500), `store/screen-*.jpg` (меньше 150 КБ), ссылка на
   политику конфиденциальности —
   <https://github.com/andreiyurik/garmin-russia-trains/blob/master/PRIVACY.md>.
4. Отправить на проверку. До одобрения приложение скрыто, но его можно открыть
   по ссылке из кабинета и поставить на свои часы — так проверяются настройки
   в Garmin Connect, которых нет при установке по USB.
5. Обновления: новый `.iq` в ту же карточку, версия выше прежней.

**Ключ.** Пакет подписан `~/.Garmin/ConnectIQ/keys/developer_key.der`.
Обновления принимаются только с той же подписью: сохраните копию ключа вне
этого компьютера (в репозиторий его не класть — `*.der` в `.gitignore`).
Без него опубликовать обновление нельзя, только новое приложение.

**Не менять** `id` в `watch/manifest.xml`: по нему магазин и часы узнают
приложение.

## Перед первой загрузкой

- Условия API Яндекс.Расписаний (<https://yandex.ru/legal/rasp_api/>):
  приложение бесплатное и публичное (п. 2.3.2), атрибуция «Данные
  предоставлены сервисом Яндекс.Расписания» со ссылкой — в настройках
  приложения (подсказка к станциям и ссылка `helpUrl`) и в описании (п. 2.3.5),
  кэширование временное (п. 3.2.4).
- Дневной лимит ключа Яндекса в кабинете разработчика: прокси при исчерпании
  отдаёт сохранённое расписание, но новые маршруты до полуночи не загрузятся.
- Доступность в России: кабинет и Connect IQ Store из России Garmin не
  гарантирует — проверить заранее, что приложение ставится с российского
  аккаунта.
